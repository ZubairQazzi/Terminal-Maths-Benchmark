# Fair mathematical traps

| Trap | Correct interpretation | Visible specification / independent check |
|---|---|---|
| Normal rank vs rank at a root | A rank-dropping sample cannot prove normal rank | Full constant block equivalence plus nonzero minor |
| Finite zero vs infinity | Reverse the pencil for infinity; exclude zero valuations | Explicit signs and reversal; generator blocks |
| p^e vs e copies of p | Same determinant can have different elementary divisors | Smith list, primary multiset and frame identities |
| Infinity partitions of equal total size | Nilpotency partition matters, not only rank B | Sizes, Weyr profile and exact KB |
| Repeated/zero right and left indices | Include multiplicity and correct rectangular side | Separate Hilbert profiles, bases, duals and dimensions |
| Polynomial vs constant equivalence | Unimodular Smith transforms need not be constant Kronecker frames | U,V must be constant and invertible |
| Independent vs saturated basis | Polynomial torsion factors can spoil a kernel module | Polynomial dual identity and leading rank |
| Arbitrary inverse vs polynomial splitting | Extra finite poles in a projector obstruct a minimum-pole argument | Both reflexive identities and exact divisibility |
| Local vs global consistency | A basis and inverse can each be valid but describe inconsistent projectors | Four cross-stage factorization identities |
| Rational vs polynomial solution | Compatibility alone does not imply a polynomial particular solution | Three response classes and Py=delta f |
| A denominator vs the least denominator | Kernel corrections must not remove a claimed pole | One exact prime-power obstruction per finite prime |

These are standard mathematical distinctions with complete public conventions. They do not rely on missing data, secret normalization, infeasible dimensions, provider errors or brittle decimal tolerances. Easy scalar and zero controls are disclosed separately and are not used to inflate the structural-case count.
