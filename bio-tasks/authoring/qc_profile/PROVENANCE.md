# QC tooling provenance

These generic QC scripts and the README generator/template were copied from the existing workspace's pinned Terminal-Bench Science tooling snapshot, with its local publisher/canary profile preserved. The original source manifest is retained. The originating project is https://github.com/harbor-framework/terminal-bench-science. This is infrastructure reuse, not reused Biology task science.

The source files have not been scientifically adapted to force a result. The supplied checklist is at `bio/authoring/QC-CHECKLIST.md`; final reports distinguish actual local shell/Harbor checks from independent reviewer assessments and from an external QC panel, which was not run. The packaged tooling makes authoring validation independent of unrelated existing workspace projects. Model-based scripts are present only as upstream source provenance; this project does not invoke them or use provider credentials.
